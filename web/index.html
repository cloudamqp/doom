Under the hood

The host's browser tab runs the Doom server. There is no backend, only static files and LavinMQ.

doomq/lobby/<game>
The host keeps a retained listing here. Its last will clears the listing when the tab closes.
doomq/games/<game>/<to>/<from>
One message per Doom packet. Players send their moves to the host, and the host sends everyone's moves back.
doomq/saves/<game>
Autosaves every two minutes, retained in the broker, so the lobby can offer to resume a game.
