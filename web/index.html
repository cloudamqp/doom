Under the hood

LavinMQ is the backend: every browser connects to it with MQTT over WebSockets, and it carries all of the game's traffic. The Doom server runs in the host's browser tab, and the rest is static files. How a game runs on MQTT, message by message

doomq/lobby/<game>
The host keeps a retained listing here. Its last will clears the listing when the tab closes.
doomq/games/<game>/<to>/<from>
One message per Doom packet. Players send their moves to the host, and the host sends everyone's moves back, once for all spectators.
doomq/saves/<game>
Autosaves every two minutes, retained in the broker, so the lobby can offer to resume a game.
doomq/watch/<game>
Where the players and monsters are, and the scores, nine times a second, for anyone who wants to watch.
